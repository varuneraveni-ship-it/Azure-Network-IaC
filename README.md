# Azure Network Infrastructure as Code

## Purpose

This repository contains Azure Network Infrastructure as Code (IaC) resources and supporting documentation.

## Objectives

- Document Azure network architecture
- Maintain Infrastructure as Code using Bicep
- Support backup and recovery initiatives
- Standardize Azure network deployments
- Provide version-controlled network configurations

## Resources

- VNets
- NSGs
- Route Tables
- Firewall Policies
- Front Door
- Private DNS
- Load Balancers
- Application Gateways
- Virtual WAN
- Virtual Hubs
